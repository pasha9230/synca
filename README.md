# Tires Sync

Система для небольшого магазина шин: разбор выгрузки склада, расчёт цен, сборка товарных фидов для торговых площадок, панель для заказов и сообщений клиентам.

- Python 3.9+, sqlite, панель на Flask, запуск по расписанию через systemd-таймеры.
- `src/tires_sync/` — код: разбор выгрузки, решения о публикации, сборка и проверка фида, панель, сообщения, заказы.
- `agent/` — агент фото на Rust (`cargo build --release`).
- `tests/` — тесты pytest; телефоны, точки, партнёры и номера заказов в них вымышленные.

## Запуск локально

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/python -m pytest -q
```

Быстрее на всех ядрах: `.venv/bin/python -m pytest -q -n auto`.

Команды: `.venv/bin/python -m tires_sync --help`. Адрес панели снаружи в коде не записан, он задаётся настройкой: `--public-base` у команд публикации; у команд вебхука — `--base-url`, иначе переменная `TIRES_PUBLIC_BASE`, иначе `public_base` в базе (например `https://panel.example.com`). Мастер-ключ задаётся файлом (`--key-file` или `TIRES_SECRET_KEY_FILE`). Ключи и пароли в репозиторий не кладутся.

Панель не рассчитана на чужие развёртывания без настройки: перед запуском в сети проверьте вход, права и HTTPS.
