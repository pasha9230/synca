# План: уведомления аккаунта точки — только точке

Решение владельца 2026-10-26: уведомления по чатам и заказам аккаунта, привязанного к точке (`point.avito_account_id`), получает только эта точка; владелец и партнёр их не получают. Аккаунты без точки (1, 2) не меняются.

## Что считается «заказом аккаунта точки»
Заказ, у которого есть чат или звонок Авито аккаунта одной точки (`order_points.point_by_account`) и нет ни одного чата или звонка аккаунта без точки, и который точка не передавала сотрудникам (`order_handoff`: «Клиент хочет заказать шины…» — точка сама просит сотрудников, это остаётся им). Заказ без чатов и звонков — не заказ аккаунта точки (как сейчас).
Чат без заказа — по его аккаунту.

## Было → стало
| Уведомление | Было | Стало (аккаунт точки) |
|---|---|---|
| Оповещение ответственному по заказу (`order_notify.deliver`: лист ожидания, конец резерва, «клиент не пришёл», ВК-команды) | Telegram ответственному сотруднику; не в панели → ВК/«Моя точка» точки заказа; «некому» → Telegram владельцу | Ответственный — пользователь этой точки с чатом Telegram → ему; иначе канал точки (ВК или «Моя точка»); не удалось или канала нет → запись на «Моя точка» и в журнал заказа, владельцу в Telegram не пишется |
| Страховка «точка не открыла оповещение за 15 минут» (`escalate_unseen`) | Telegram владельцу | Для заказов аккаунта точки не передаётся владельцу |
| Колокольчик, счётчик «Уведомления», точки у номеров (`order_alerts.page_rows`) для сотрудников (не точки) | Все записи журнала всех заказов и все чаты без заказа | Без записей заказов аккаунтов точек и без чатов без заказа аккаунтов точек |
| То же для пользователя точки | Заказы точки, чаты её аккаунта | Без изменений |
| «Срочно ответить», «Перезвонить» | Уже без аккаунтов точек | Без изменений |
| Передача клиента точкой сотрудникам (handoff), «Заказа нет в CRM», ежедневная сводка, сбои системы | Сотрудникам | Без изменений (точка сама просит сотрудников / не уведомления по чату) |

Аккаунты 1/2: без изменений, в т.ч. заказы, доставленные на точку (ответственному, как сейчас).

## Решения
(a) Владелец по-прежнему видит в панели всё (заказы, чаты, журнал); перестают приходить только толкающие уведомления: Telegram и колокольчик/счётчик.
(b) Нет получателя у точки → запись на «Моя точка» и красная запись в журнале заказа (видна точке); владельцу Telegram не уходит.
(c) Заказы аккаунтов 1/2, доставленные на точку, — как сейчас.

## Данные
Миграции нет: всё вычисляется из существующих `avito_chat`, `avito_call`, `point`, `order_handoff`.
