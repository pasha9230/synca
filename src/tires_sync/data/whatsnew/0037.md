## Заказы: лист ожидания — предложение клиенту, когда шина появилась
roles: owner, partner, chats
**Что сделано:** когда для заказа на «Ожидает наличие» появляется нужная шина или аналог, панель готовит сообщение клиенту и разбирает его ответ «Да» / «Нет».

**Как работает:**
- Текст: «Добрый день. Ранее вас добавляли в лист ожидания…» с названием и ценой; для аналога — «появился аналог». Правится в «Настройка → Шаблоны сообщений».
- Переключатель «Автоотправка предложений из листа ожидания» там же, по умолчанию выключен: вместо отправки менеджеру задача с готовым текстом и кнопкой «Отправить». Включён — сообщение уходит само, один раз за ожидание.
- Нет цены — задача «поставьте цену»: впишите цену в текст и отправьте. Нет чата Авито — задача «позвоните клиенту» с именем, телефоном, составом заказа и ценой.
- Ответ «Да» — задача «Клиент ответил «Да»: позовите менеджера», заказ остаётся в ожидании. «Нет» — заказ в «Отмена» с причиной «клиент отказался от ожидания», строки ожидания сохраняются. Любой другой ответ — задача менеджеру.
- Заказ в ожидании без строк «Что нужно клиенту», но с позициями — строки берутся из позиций с артикулами сами.

**Затрагивает разделы:** «Заказы», «Задачи», «Настройка → Шаблоны сообщений».
