# Участие в проекте

Pull request'ы принимаются от участников репозитория: отдельная ветка, зелёная проверка `pytest`, правила в [CLAUDE.md](CLAUDE.md). Критичные файлы вливаются только после одобрения владельца ([.github/CODEOWNERS](.github/CODEOWNERS)). Для остальных код открыт только для просмотра (лицензии нет, см. [README.md](README.md)).

Об уязвимостях сообщайте закрыто, как описано в [SECURITY.md](SECURITY.md).
