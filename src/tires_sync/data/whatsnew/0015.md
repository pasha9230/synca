## Каталог для клиента: разноширокие без размера оси
roles: owner, partner, client
**Что сделано:** если размер одной из осей не указан, список «Только передняя ось» или «Только задняя ось» больше не показывает весь каталог.

**Как работает:**
- Пустое поле оси по-прежнему означает «любое значение»: комплекты подбираются из шин той же модели любого размера.
- В списке «Только …» для оси без размера вместо шин подсказка: «Укажите размер передней оси, чтобы увидеть шины без пары» (или задней).
- Как только для оси указана ширина, профиль или диаметр, её список заполняется как раньше.

**Затрагивает разделы:** «Каталог для клиента» («Вид 2», галочка «Разноширокие»).

## Каталог: «Разноширокие» без размера оси
roles: owner, partner
**Что сделано:** в каталоге офиса с галочкой «Разноширокие» то же правило: ось без размера не выводит весь каталог в «Только передняя ось» или «Только задняя ось».

**Как работает:**
- Комплекты считаются как раньше, пустое поле оси означает «любое значение».
- В списке «Только …» оси без размера стоит подсказка указать её размер.

**Затрагивает разделы:** «Каталог» (галочка «Разноширокие»).
