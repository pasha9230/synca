## Заказы: отдельный этап «Согласование возврата»
roles: owner, partner, chats, point
**Что сделано:** между «На ОТХ» и «На возврат» появилась отдельная колонка «Согласование возврата». Ответственный получает задачу согласовать возврат с поставщиком.

**Как работает:**
- На седьмой день хранения заказ переходит на согласование автоматически. Оператор может перевести его раньше.
- После подтверждения поставщика оператор указывает дату возврата. Заказ переходит в «На возврат», а точка видит дату и может скачать прикреплённый акт МХ-3. Один акт можно загрузить для нескольких заказов одной точки на одну дату.
- На этапах «Согласование возврата» и «На возврат» менеджер точки не может продать шины. Если продажа всё же нужна, обратитесь в офис для отмены запроса поставщику и возврата шин на ОТХ.

**Затрагивает разделы:** «Заказы», «На ОТХ», «Рабочее место» точки.

## Каталог: «Наша цена» у позиций из архива
roles: owner, partner
**Что сделано:** «Нашу цену» можно изменить прямо в строке каталога, даже если позиция исчезла из текущей выгрузки поставщика.

**Как работает:**
- Найдите позицию в каталоге, нажмите на ячейку «Наша цена» и сохраните изменение. Оно попадёт в черновик. Чтобы применить цену, нажмите «Применить».

**Затрагивает разделы:** «Каталог».

## Фиды: восстановлена сборка после истечения срока общих ID
roles: owner, partner
**Что сделано:** устранена причина, по которой проверка фида могла остановить публикацию после окончания срока действия общих ID объявлений Авито.

**Как работает:**
- После окончания срока система подставляет собственный ID объявления для каждого аккаунта. Проверка фида перед публикацией остаётся обязательной.

**Затрагивает разделы:** «Фиды».
