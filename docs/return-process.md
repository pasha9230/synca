# Возврат шин с ОТХ

## Этапы

1. **На ОТХ**: шины находятся на точке. Продажа с ОТХ разрешена, пока позиция не отмечена на возврат.
2. **Согласование возврата**: на седьмой день заказ переходит сюда автоматически; оператор может перевести его раньше. Шины сняты с продажи, ответственному ставится задача. Точка не может нажать «Продать». Если поставщик отказал или шины нужно продать, оператор сначала отменяет запрос поставщику и возвращает заказ на ОТХ.
3. **На возврат**: оператор подтвердил согласие поставщика и указал дату. Точка видит дату и акт МХ-3. Продажа запрещена. Дата по умолчанию — ближайший понедельник, среда или пятница; согласованную другую дату можно указать вручную.
4. **Вернули поставщику**: точка подтвердила передачу по акту, сумма возврата оформлена. Если закупочная сумма неизвестна, заказ остаётся на «На возврат» до заполнения суммы.

Отмена согласования возвращает заказ с «На возврат» в «Согласование возврата». Уже открытые заказы на прежнем объединённом этапе без записи о согласовании переносятся в новую колонку при миграции. Дата входа в этап, задачи и отметки сохраняются. Заказы с согласованием остаются на «На возврат».

При отметке отдельных шин заказ с другими, ещё продаваемыми шинами остаётся в колонке «На ОТХ»: одна карточка не может находиться в двух колонках одновременно. Отмеченные штуки исключаются из фида и предложений «Взять с ОТХ», а точка видит карточку во вкладке «Согласование возврата». Продажа всего такого заказа запрещена и точке, и офису до отмены отметки оператором после согласования с поставщиком. Для этого на странице ОТХ есть кнопка «Отменить запрос»; она снимает только ожидающую отметку, не меняя число шин, уже переданных поставщику. Для переноса всей карточки в колонку «Согласование возврата» оператор переводит её из ОТХ; после подтверждения поставщика она переходит в «На возврат».

Если оператор загружает общий акт для отмеченных позиций, система сначала отделяет отмеченное количество в заказ на этапе согласования, затем подтверждает его на согласованную дату. Остальные шины остаются на ОТХ. Один акт может покрывать несколько заказов **одной точки и одной даты**. Загрузка акта подтверждает все отмеченные количества выбранных заказов; если поставщик принял только часть, сначала укажите согласованное количество в карточке заказа.

## Письмо поставщику

Отправка через Gmail подключается после настройки ящика отправителя и адреса поставщика. Ответы поставщика оператор обрабатывает вручную: сверяет согласованные позиции и количества, указывает дату, подтверждает возврат и прикрепляет полученный акт.

План отправки запросов: **вторник и пятница, 13:00 по Москве**. Создаётся **одно письмо для каждой точки** со всеми её позициями, поступившими на согласование с прошлого отправленного письма. Новые позиции после 13:00 ждут следующего планового письма; оператор может нажать «Отправить сейчас» для срочного запроса. После подтверждения отправки Gmail каждая позиция из письма получает тег «Письмо отправлено» и остаётся на этапе «Согласование возврата». Правило одинаково для плановой и срочной отправки. При ошибке отправки тег не ставится. Позиции с подтверждённой отправкой исключаются из следующего пакета в рамках того же запроса на возврат.

Тема: `Возврат. «{точка}». {текущая дата по Москве}`.

Письмо начинается словами: `Добрый день. Прошу согласовать на возврат с «{точка}»`.

Для **каждой позиции** отдельным блоком перечисляются: наименование позиции, артикул, количество шин, номер заказа MIM, номер перемещения MIM (в поле письма «Номер счета (перемещения) MIM»). Номера берутся из исходной закупки позиции, в том числе когда заказ был разделён после ОТХ. Если поставщик согласовал часть позиций или указал разные даты, оператор обрабатывает согласованные количества отдельно и прикрепляет акт МХ-3 к соответствующей точке и дате.

## Откат

До публикации: закрыть PR. После публикации: вернуть предыдущий коммит и восстановить положение заказов по резервной копии базы. Миграция не удаляет планы возвратов и не меняет даты входа в этап.
